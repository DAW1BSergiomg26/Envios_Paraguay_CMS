## 🌎 Descripción

**Envios_Paraguay_CMS** es una plataforma web moderna orientada a la gestión de envíos, repartos y logística internacional entre España y Paraguay.

El proyecto combina una experiencia visual premium con una arquitectura sólida basada en Spring Boot, incorporando:

- CMS administrativo avanzado
- Dashboard premium
- Gestión multimedia
- Diseño cinematográfico
- Responsive Design
- Arquitectura MVC profesional
- Sistema bilingüe
- Experiencia de usuario moderna
