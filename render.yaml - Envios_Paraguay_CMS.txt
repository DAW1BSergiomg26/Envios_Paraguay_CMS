render.yaml - Plantilla de Infraestructura como Código (IaC) para Envios_Paraguay_CMS
Este archivo de configuración está adaptado para desplegar tu aplicación Spring Boot con Docker en Render, manteniendo las buenas prácticas de seguridad para no exponer credenciales sensibles en el repositorio.
Estructura del archivo render.yaml
Crea un archivo llamado render.yaml en la raíz de tu repositorio con el siguiente contenido:
services:
 - type: web
   name: envios-paraguay-cms
   env: docker
   region: frankfurt
   plan: free
   branch: main
   envVars:
     - key: SPRING_PROFILES_ACTIVE
       value: prod
     - key: SPRING_DATASOURCE_URL
       value: jdbc:postgresql://tu-host-de-neon-db:5432/tu_base_de_datos?sslmode=require
     - key: DB_USERNAME
       value: tu_usuario
     # Las credenciales sensibles como contraseñas o tokens deben configurarse
     # de forma segura desde el panel de Render para evitar filtrarlas en Git.

Recomendaciones de seguridad
* Variables de entorno sensibles: No escribas contraseñas reales (como DB_PASSWORD o ADMIN_PASSWORD) directamente dentro de este archivo si tu repositorio es público o compartido. Configúralas directamente en la sección Environment del panel de Render.
* Base de datos: Si utilizas Neon DB como base de datos en la nube, asegúrate de que la URL incluya los parámetros correctos de SSL tal como los has estado probando en el proyecto.
